The Long/Short Portfolio

The model operates on a frozen fixture of 60 positions (40 long, 20 short) totaling $400.0M Gross Notional and $60.0M Net Long, supported by $120.0M Fund NAV (3.3x gross leverage).

Hard-to-borrow (HTB) securities constitute $15.5M (3.9%) of total notional, establishing a hard operational constraint for prime brokers without dedicated stock-loan inventory.

Code 
book %>%
  arrange(desc(notional)) %>%
  head(10) %>%
  mutate(is_htb = ifelse(is_htb, "HTB", "General Collateral")) %>%
  select(ticker, sector, side, notional, adv_usd, beta, is_htb) %>%
  gt() %>%
  tab_header(
    title = md("**Synthetic Long/Short Book (Top 10 Largest Positions)**"),
    subtitle = "Position-level notional, market liquidity, and hard-to-borrow status"

  cols_label(
    ticker = "Ticker",

  fmt_currency(columns = c(notional, adv_usd), decimals = 0) %>%

Sector Composition

Understanding sector balance is critical because the Portfolio Margin regime at PB-B provides margin relief on offsetting long/short exposures within correlated industries.

Code 
book %>%
  group_by(sector, side) %>%
  summarize(notional_m = sum(notional) / 1e6, .groups = "drop") %>%
  ggplot(aes(x = reorder(sector, notional_m), y = notional_m, fill = side)) +
  geom_col(position = "stack", width = 0.65) +
  coord_flip() +
  scale_fill_manual(values = c("LONG" = "#2c7bb6", "SHORT" = "#d7191c")) +
  scale_y_continuous(labels = label_dollar(suffix = "M")) +
  labs(
    title = "Gross Portfolio Exposure by Sector",
    subtitle = "Aggregated long vs. short notional across industry sleeves",
    x = NULL,
    y = "Notional ($ Millions)",
    fill = "Side"
  ) +
  theme_minimal(base_size = 11) +
  theme(
    legend.position = "bottom",
    panel.grid.minor = element_blank()
  )

```{r setup, include=FALSE}

library(readr)
library(dplyr)
library(ggplot2)
library(scales)
library(gt)
library(yaml)

book  <- read_csv("data/synthetic_book.csv", show_col_types = FALSE)
terms <- yaml::read_yaml("data/pb_terms.yaml")

# Calculations
n_total  <- nrow(book)
n_long   <- sum(book$side == "LONG")
n_short  <- sum(book$side == "SHORT")
gross_usd <- sum(book$notional)
net_usd   <- sum(book$notional[book$side == "LONG"]) - sum(book$notional[book$side == "SHORT"])
nav_usd   <- terms$general$fund_nav
htb_usd   <- sum(book$notional[book$is_htb])

# Pre-formatted text variables
txt_n_total  <- sprintf("%d", n_total)
txt_n_long   <- sprintf("%d", n_long)
txt_n_short  <- sprintf("%d", n_short)
txt_gross    <- sprintf("$%.1fM", gross_usd / 1e6)
txt_net      <- sprintf("$%.1fM", net_usd / 1e6)
txt_nav      <- sprintf("$%.1fM", nav_usd / 1e6)
txt_leverage <- sprintf("%.1fx", gross_usd / nav_usd)
txt_htb_usd  <- sprintf("$%.1fM", htb_usd / 1e6)
txt_htb_pct  <- sprintf("%.1f%%", (htb_usd / gross_usd) * 100)

```

## The Long/Short Portfolio

The model operates on a frozen fixture of `{r} txt_n_total` positions (`{r} txt_n_long` long, `{r} txt_n_short` short) totaling **`{r} txt_gross` Gross Notional** and **`{r} txt_net` Net Long**, supported by **`{r} txt_nav` Fund NAV** (`{r} txt_leverage` gross leverage). 

Hard-to-borrow (HTB) securities constitute **`{r} txt_htb_usd` (`{r} txt_htb_pct`)** of total notional, establishing a hard operational constraint for prime brokers without dedicated stock-loan inventory.

Computational Reproducibility & Environment Audit

Deterministic Solver Tolerances, Toolchain Manifest, and Build Pipeline

Institutional Reproducibility Mandate

In institutional treasury modeling and quantitative risk oversight, analytical models must not function as black boxes. For investment committees, credit rating agencies, and regulatory auditors, mathematical reproducibility is the foundational benchmark of sound governance.

This suite is implemented entirely in R and Quarto, binding optimization output dynamically into prose. Every table, dual shadow price (‭\(\lambda\)‬), sector heatmap, and stress-frontier coordinate is generated deterministically at render time from version-controlled source files.

Toolchain & Software Architecture

The computational pipeline relies on the GNU Linear Programming Kit (GLPK) interfaced through the ompr algebraic modeling ecosystem.

Data Layer Attributes

  • Portfolio Asset Side (data/synthetic_book.csv): 60 positions detailing gross notional (‭\(N_i\)‬), side (LONG vs. SHORT), sector classifications, average daily volume (adv_usd), market betas (‭\(\beta_i\)‬), and hard-to-borrow indicators (is_htb).

Solver Determinism & Convergence Parameters

Because the primary allocation framework is formulated as a continuous linear program (LP), the solution space forms a convex polytope. The Simplex algorithm guarantees global optimality without stochastic variation.

GLPK Solver Convergence & Numerical Tolerances

Mathematical Parameter Assigned Threshold Governance & Analytical Role

Dual Simplex Feasibility 1e-07 Tolerance governing the precision of shadow prices (lambda values)
Integer Tolerance (MILP) 1e-05 Absolute integrality threshold for binary no-split custody variables
Branch-and-Bound Time Limit 60 seconds Maximum search horizon for integer tree exploration (solves in <1.5s)

Step-by-Step Pipeline Replication

To reproduce this documentation suite and execute all underlying optimization runs on a local workstation:

  1. Environment Restoration (renv) Restore the locked computational environment to ensure exact package version parity:
# Initialize renv and restore verified dependencies
install.packages("renv")
renv::restore()
  1. Executing Solver Test Run Verify that the underlying GLPK engine compiles and converges via the R console:
# Load and execute the baseline LP
source("R/build_lp.R")
source("R/solve_lp.R")

lp_fixture <- build_allocation_lp()
solution   <- solve_allocation_lp(lp_fixture)

# Confirm convergence status and baseline cost
cat("Solver Status:", solution$solver_status, "\n")
cat("Annual Financing Expense:", scales::dollar(solution$annual_financing_cost), "\n")
  1. Compiling the Quarto Documentation Suite Render the complete multi-chapter book to HTML:
# Render all chapters to the output directory
quarto render

# Alternatively, launch a local live-reloading preview server
quarto preview
